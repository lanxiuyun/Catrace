一块小窗，背后是一套事件系统

每张卡片是一个微型界面：有状态、有按钮、有生命周期。插件不各弹各的窗口——感知、事件、渲染三层分离，所有内容走同一条事件协议，进同一块小窗。

行为感知

键鼠忙闲、系统声音、蓝牙设备、AI hook——安静地知道桌面上发生了什么。

事件总线

统一协议承载每条事件的生命周期：弹出、更新、点掉，一个 id 跟到底。

桌面小窗

右下角堆叠、点击操作、滑出收拢。里面显示什么，由插件说了算。

活跃感知只服务一件事：让卡片在对的时机出现。判断只发生在本机——判断是为了少打扰，不是为了监视。

内置开箱即用，插件按需加装

本地回环 Event API：脚本、CI、你自己的 agent，都能把事件发进桌面小窗。

# 本地回环，Token 在 Catrace 调试页生成
curl -X POST http://127.0.0.1:23457/v1/events \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"title":"构建完成","body":"exit 0 · 用时 42s","level":"success"}'
