# Dashboard

主页面，展示今日统计和活动时间轴。过往天的分钟记录仍在 SQLite `records`，Dashboard 不提供日期切换；外置插件用 `plugin.activity.getRecords`（见 [[plugin-center]]）。

## 涉及文件

- `src/app/pages/Dashboard.tsx` — 页面布局（React 版，替代 `views/mainWindow/Dashboard.vue`）
- `src/app/pages/dashboard/TimelineGrid.tsx` — 详细视图热力图
- `src/app/pages/dashboard/TimelineWindows.tsx` — 概览视图 block 卡片
- `src/utils/timeBlocks.ts` — 前端 block 切分算法

```
├───────────────────────────────────────────────────────────┤
│ 11月3日 星期二 ..................... (隐藏统计 ⚪)          │
│ ┌───────────────────────────────────────────────────────┐ │
│ │ 今日活跃                       活跃占比 16%  休息 12h   │ │
│ │ 2h 22m                        活跃时段 3 个             │ │
│ │ ▬▬▬▬▬▬▬▬▬▬||||||||||||||||||||||||||||||||||||||||     │ │
│ │ ● 活跃            已记录 14h 22m             ● 休息     │ │
│ └───────────────────────────────────────────────────────┘ │
│ 今日活动记录 12 条 ................. (概览｜详细)           │
│ ┌───────────┐ ┌───────────┐ ┌───────────┐                 │
│ │ ● 进行中 ⌄ │ │ ● 休息   ⌄ │ │ ● 活跃   ⌄ │                 │

│ │ 10m        │ │ 1h 12m     │ │ 45m        │                │
│ └───────────┘ └───────────┘ └───────────┘                 │
└───────────────────────────────────────────────────────────┘
```

日期是页面主标题（`h1`，1.75rem/700），星期用次级色跟在后面；「隐藏统计」标签和 Radix `Switch` 收在同一颗胶囊里，靠右对齐（`<label htmlFor>` 绑到开关上，点文字也能切）。日期走 `Intl.DateTimeFormat.formatToParts`，所以 en-US（星期在前）和 zh-CN（星期在后）都能只给星期降级颜色；拼回来时要把 en-US 那个前导 `", "` 去掉。

`Switch` 默认跟随 Radix 的 iris 强调色（偏紫），`dashboard.css` 里把轨道压成系统蓝纯色；改这里时要确认 `[data-state='checked']::before` 的选择器特异性仍然压过 Radix 自带样式（Radix 用 `:where()`，0 权重，所以 `[data-state='checked']` 这条能压住它，暗色规则必须排在最后）。

## 主视觉卡

一张 `.summary` 卡承担原来四张等权统计卡的分层，是全页唯一的焦点：

- **今日活跃**：block 语义算出的活跃时长，全页最大数字（2.5rem/700，`tabular-nums`），左边一行小标签写「今日活跃」。
- **右侧三个次级指标**：活跃占比 / 休息 / 活跃时段（标签 0.75rem 次级色，数值 1.125rem/600），和左侧大数字同一个底边对齐。
- **活跃/休息占比条**：整条 = 已记录时长（活跃 + 休息）。两段宽度用**未取整**的比例算 `flex-grow`，所以 16%+84% 加起来不会露缝；只有旁边的文字才四舍五入。图例行左「● 活跃」、中间「已记录 14h 22m」、右「● 休息」——把分母交代清楚。
- 记录时长为 0 时两段 `flex-grow` 都是 0，只剩一条灰色空槽，不会出现「100% 休息」的假象。

**为什么是条不是环**：16% 的环形大半是空的，视觉上像「没完成」；占比条表达的是「已记录时间里活跃/休息的构成」，而且和下面活动卡的单行信息节奏一致。

## 统计口径

- **活跃**：block 语义计算——活跃 block 全部时长 + 休息 block 里的活跃分钟
- **休息**：休息 block 里实际休息的分钟
- **活跃占比**、**活跃时段**：基于 block 语义（占比 = 活跃 /（活跃+休息），不含未记录时段）

## 壳层材质

本页重设计同时换了壳层，`src/styles/theme.css` 新增 `--ct-bg-glow` / `--ct-sidebar-bg` / `--ct-sidebar-border` / `--ct-nav-hover` / `--ct-nav-active`：

- 窗口背景 = `--ct-bg` + 顶部左上一团极淡的系统蓝柔光（`.ct-workspace` 的 radial-gradient），白色卡片才有「受光」的层次，而不是贴在平灰上；
- 侧边栏：宽窗口是带文字的 10rem（透光材质 `blur(30px) saturate(180%)`，选中项白色胶囊 + 系统蓝图标）；视口窄于 62rem 时收成 **3.75rem 图标栏**，命中区 2.25rem 见方、图标放大到 1.125rem，标签文字隐藏但保留 `aria-label`，鼠标悬停显示 `data-label` 做的深色小浮层（`::after`，和分钟条 tooltip 同一套材质）。
- 这些 token 全应用共用，所以其它页面会跟着变（配色一致是好事）。逐页重设计时不要再各自写死背景/侧栏颜色。

## 空态

当天一条记录都没有（`records.size === 0`）时，不画 block 网格、也不显示「概览/详细」切换器，只留一个居中的空态说明；`blocks` 在无记录时直接返回空数组，所以计数徽标和统计卡一起归零，不会出现「休息 10h」这种凭空捏出来的时段。旧实现会先渲染一个 00:00→现在的「无记录休息 block」，再在下面补一句空态，自相矛盾。

## 滚动

普通页面由 `PageScroll` 负责滚动（见 [[app-shell]]）。Dashboard 根节点不要自行创建同方向滚动，也不要使用 `min-height: 100vh`。

## 时间轴双视图

- **概览**（默认）：block 卡片网格 `repeat(auto-fit, minmax(15.625rem, 1fr))`，点击整行展开
- **详细**：24h×60min 热力图，当前分钟用系统蓝细环 + 呼吸高亮，悬停出读数（只读，不可点击）

详见 [[timeline]]。
