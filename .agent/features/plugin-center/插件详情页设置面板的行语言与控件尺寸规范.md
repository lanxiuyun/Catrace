# 插件详情页设置面板的行语言与控件尺寸

插件详情（整页详情）里内置插件的设置面板（目前只有久坐提醒）是宿主自己的 React 组件，不是插件 UI：卡片、行、控件的尺寸沿用系统设置页那套语言，但外层是 48.5rem 单列（比系统设置的 22rem 瓦片宽得多），所以「字段该多宽、控件该多大」必须按这里的规矩来，不能照抄系统设置页的卡片尺寸。

## 涉及文件

- `src/app/pages/Plugins.tsx` — 设置数据的读取 / 500ms 防抖保存 / 测试通知，把面板塞进 `PluginCenter`
- `src/app/pages/plugins/RestSettings.tsx` — 久坐提醒的四组卡：提醒偏好时间 / 提醒方式 / 提醒文本内容 / 通知测试
- `src/app/pages/plugins/PluginSettingRow.tsx` — 设置行外壳（默认行 + `stack` 行）
- `src/app/pages/plugins.css` — `.ct-plugin-groups` / `.ct-plugin-group` / `.ct-plugin-row` / 滑块 / 值 chip / 背景图预览
- `src/app/radix-theme.css` — Radix token 映射与全站控件 hover（面板里不要重复写 hover）
- `src/i18n/locales/zh-CN.ts` / `en-US.ts` — `plugins.rest.*` 文案

## 结构

```
.ct-plugin-groups           （列，gap 1rem）
└─ .ct-plugin-group         （白卡：padding 1.125rem 1.25rem 1rem，圆角 1.125rem，--ct-border-card）
   ├─ .ct-plugin-group-title（12px / 600 / muted，margin-bottom .375rem）
   └─ .ct-plugin-row × N
```

行有两种形态（`PluginSettingRow`）：

- 默认：左 `.ct-plugin-row-copy`（标题 .875rem/600 + 说明 .75rem muted），右 `.ct-plugin-row-control`（右对齐、不参与伸缩）
- `stack`：文案在上、控件在下吃满一行 —— 输入框 / 文本域 / 背景图预览用它

相邻行之间的 `--ct-border` hairline 由 `.ct-plugin-row + .ct-plugin-row` 自动画，首行 `padding-top: 0`。不要手插分隔线。

## 尺寸与颜色

- 控件统一 32px（Radix `size="2"`）：单行输入、下拉、行内按钮都用 2。`size="1"`（24px）只用于提示条里的行内小动作（系统设置的 SysNotify 是例子），不要用在正常设置行 —— 「测试通知」按钮曾经是 1，比同页所有控件小一号。
- 字段宽度：`is-stack` 的控件列 `width: 100%`，单行 / 多行输入吃满卡内容宽（934px 窗口下约 729px）。多行输入给 `resize="vertical"`，和系统设置页「排除列表」同一个手感。
- 滑块：轨 4px / 滑块 15px（`--slider-track-size` / `--slider-thumb-size`），控件列 `flex: 0 1 20rem`；右侧 `.ct-plugin-value` 值 chip（等宽字体、min-width 4rem、右对齐）与下拉右边缘对齐。
- 颜色：**蓝色只给可操作 / 当前状态的控件** —— 开关、聚焦环、滑块已选段、安装按钮。卡片底色、文案、值 chip 保持中性。
- 滑块配色：轨道 `--ct-surface-2`，已选段 `--ct-accent`（浅色 #007aff / 深色 #0a84ff），滑块白底投影；填充段去掉 Radix 的内描边（4px 轨道上那圈深边会把蓝色切出一道边）。
  **不要**把 `.rt-SliderRange` 和 `.rt-SliderTrack` 设成同一个颜色 —— 已选段会直接消失，三个滑块看起来一模一样，只能去右边读数字。

## Radix 类名（写错不报错，样式静默失效）

| 控件 | 根节点 | 内部 |
| --- | --- | --- |
| 单行输入 | `.rt-TextFieldRoot` | `.rt-TextFieldInput` |
| 多行输入 | `.rt-TextAreaRoot` | `.rt-TextAreaInput` |
| 按钮 | `.rt-Button`（+ `.rt-BaseButton`） | — |
| 下拉 | `.rt-SelectTrigger` | — |
| 开关 | `.rt-SwitchRoot` | — |
| 滑块 | `.rt-SliderRoot` / `.rt-SliderTrack` / `.rt-SliderRange` / `.rt-SliderThumb` | — |
| 分段控件 | `.rt-SegmentedControl*`；本站 macOS 胶囊样式是 `shell.css` 的 `.ct-segmented`（概览页在用） | — |

2026-11 踩过的坑：面板 CSS 写了 `.rt-TextArea`，它其实是内部 `<textarea>` 的类名，根节点是 `.rt-TextAreaRoot`，于是 `width` 规则整个失效、多行输入缩成控件默认的 ~176px。改完选择器要到渲染出的 DOM 或 `node_modules/@radix-ui/themes/src/components/*.tsx` 里核对一次根节点类名。

## 加一行设置项时改哪里

1. `RestSettings.tsx` 加一个 `PluginSettingRow`（普通行 / `stack` 行），不要自己写 padding / 卡片 / 根 max-width —— 外壳归 `.ct-plugin-group` / `.ct-plugin-row`。
2. 文案加到 `src/i18n/locales/zh-CN.ts` 与 `en-US.ts` 的 `plugins.rest.*`，不要在组件里写死中文。
3. 控件用 Radix `size="2"`；输入类让 `.ct-plugin-row-control` 的 100% 宽度生效；多行输入补 `resize="vertical"`。
4. 需要新颜色 / 新 hover 时先看 `src/app/radix-theme.css` 与 `shell.css` 有没有现成语言，别在本文件里造第三套。
