# 插件详情页设置面板的行语言与控件尺寸

插件详情（整页详情）里内置插件的设置面板（目前只有久坐提醒）是宿主自己的 React 组件，不是插件 UI：卡片、行、控件的尺寸沿用系统设置页那套语言，但外层是 48.5rem 单列（比系统设置的 22rem 瓦片宽得多），所以「字段该多宽、控件该多大」必须按这里的规矩来，不能照抄系统设置页的卡片尺寸。

## 涉及文件

- `src/app/pages/Plugins.tsx` — 设置数据的读取 / 500ms 防抖保存 / 测试通知，把面板塞进 `PluginCenter`
- `src/app/pages/plugins/RestSettings.tsx` — 久坐提醒的三组设置：提醒节奏 / 提醒方式 / 提醒内容（含通知测试）
- `src/app/pages/plugins/PluginSettingRow.tsx` — 设置行外壳（默认行 + `stack` 行）
- `src/app/pages/plugins.css` — `.ct-rest-section-head` 浅色组标题、`.ct-rest-section-body` 白卡与共享设置行
- `src/styles/heroui.css` — HeroUI 样式入口与字段变体约定；宿主控件不再走 Radix
- `src/i18n/locales/zh-CN.ts` / `en-US.ts` — `plugins.rest.*` 文案

## 结构

```
.ct-rest-settings
└─ .ct-rest-section
   ├─ .ct-rest-section-head （卡片外的浅色小标题）
   └─ .ct-rest-section-body （一张白色卡片）
      └─ .ct-plugin-row × N
```

行有两种形态（`PluginSettingRow`）：

- 默认：左 `.ct-plugin-row-copy`（标题 .875rem/600 + 说明 .75rem muted），右 `.ct-plugin-row-control`（右对齐、不参与伸缩）
- `stack`：文案在上、控件在下吃满一行 —— 输入框 / 文本域 / 背景图预览用它

相邻行之间的 `--ct-border` hairline 由 `.ct-plugin-row + .ct-plugin-row` 自动画，首行 `padding-top: 0`。不要手插分隔线。

## 尺寸与颜色

- 控件统一用 HeroUI：单行输入、下拉、行内按钮默认 `size="sm"`（32px）；输入类用 `variant="secondary"`，白色卡片上才有浅灰底与边界。24px 的小动作只用于提示条里的行内按钮，不要用在正常设置行。
- 字段宽度：`is-stack` 的控件列 `width: 100%`，单行 / 多行输入吃满卡内容宽（934px 窗口下约 729px）。多行输入给 `rows` 并允许纵向 resize，和系统设置页「排除列表」同一个手感。
- 滑块：`SettingSlider` 是本地 helper，内部仍用 HeroUI `Slider`；轨道 / 滑块尺寸通过 CSS 变量收紧，右侧 `.ct-plugin-value` 值 chip（等宽字体、min-width 4rem、右对齐）与下拉右边缘对齐。
- 颜色：**蓝色只给可操作 / 当前状态的控件** —— 开关、聚焦环、滑块已选段、安装按钮。卡片底色、文案、值 chip 保持中性。
- 滑块配色：轨道 `--ct-surface-2`，已选段 `--ct-accent`（浅色 #007aff / 深色 #0a84ff），滑块白底投影。

背景区域复用真实全屏提醒的纯画面，不单独复制一份 UI；缩放、透明度、默认文案与非交互约定见[全屏提醒](../fullscreen-reminder/README.md#设置页实时预览)。

## 外部插件 UI 的 Radix 类名（宿主面板已不用）

宿主插件设置面板已经全部换成 HeroUI；下面的 Radix 类名表只适用于**外部插件导出的 SettingsComponent**，插件 UI 仍由宿主注入 Radix。宿主页面不要再新增 `.rt-*` 选择器。

| 控件 | 根节点 | 内部 |
| --- | --- | --- |
| 单行输入 | `.rt-TextFieldRoot` | `.rt-TextFieldInput` |
| 多行输入 | `.rt-TextAreaRoot` | `.rt-TextAreaInput` |
| 按钮 | `.rt-Button`（+ `.rt-BaseButton`） | — |
| 下拉 | `.rt-SelectTrigger` | — |
| 开关 | `.rt-SwitchRoot` | — |
| 滑块 | `.rt-SliderRoot` / `.rt-SliderTrack` / `.rt-SliderRange` / `.rt-SliderThumb` | — |

2026-11 踩过的坑（当时宿主面板还在用 Radix）：面板 CSS 写了 `.rt-TextArea`，它其实是内部 `<textarea>` 的类名，根节点是 `.rt-TextAreaRoot`，于是 `width` 规则整个失效、多行输入缩成控件默认的 ~176px。外部插件 UI 改选择器时仍要到渲染出的 DOM 或 `node_modules/@radix-ui/themes/src/components/*.tsx` 里核对一次根节点类名。

## 加一行设置项时改哪里

1. `RestSettings.tsx` 加一个 `PluginSettingRow`（普通行 / `stack` 行），不要自己写 padding / 卡片 / 根 max-width —— 外壳归 `.ct-plugin-group` / `.ct-plugin-row`。
2. 文案加到 `src/i18n/locales/zh-CN.ts` 与 `en-US.ts` 的 `plugins.rest.*`，不要在组件里写死中文。
3. 控件用 HeroUI（默认 `size="sm"`），输入类用 `variant="secondary"`；让 `.ct-plugin-row-control` 的 100% 宽度生效；多行输入补 `rows`。
4. 需要新颜色 / 新 hover 时先看 `src/styles/heroui.css` 与 `plugins.css` 有没有现成语言，别在本文件里造第三套。
