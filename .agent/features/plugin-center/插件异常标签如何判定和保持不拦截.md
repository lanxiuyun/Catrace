# 插件资源异常观测

资源异常是诊断信号，不是权限系统或资源限额。宿主按插件 id 记录资源活动，写 warning 并标记 `anomalous`；原调用继续执行。

## 判定

| 类型 | 条件 |
|---|---|
| 高频事件 | 60 秒内发布超过 60 个 Event |
| 单次大 Event | 序列化达到 8 MiB |
| 连续 Storage 写入 | 60 秒内超过 16 MiB |
| 单次大 Storage | 序列化 value 达到 8 MiB |
| 后台 WebView 高内存 | 每 15 秒采样，连续 4 次达到 128 MiB |

实现以 [plugin_commands.rs](../../../src-tauri/src/plugin_commands.rs) 为准。内存采样来自 [PluginHost.vue](../../../src/views/toastWindows/PluginHost.vue) 的 `performance.memory`；平台不支持时跳过，且它不代表 sidecar / OS working set。

## 数据与界面边界

- [plugins.rs](../../../src-tauri/src/plugins.rs) 在内存中保存 `anomalous`，rescan 按 id 保留，重启清除。
- 后端发送 `catrace:plugin-anomaly`，列表数据也可携带标记。
- 当前 React [PluginCenter.tsx](../../../src/app/pages/plugins/PluginCenter.tsx) 展示清单错误 `info.error`，没有监听该异常事件或渲染 `anomalous` 标签。不能将资源异常标记描述为已有前端提示。

阈值只用于诊断，不拒绝、不截断、不限流、不丢弃事件或存储写入；warning 要包含插件 id 与原因。
