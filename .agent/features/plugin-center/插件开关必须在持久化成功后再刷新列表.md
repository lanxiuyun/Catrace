# 插件启停与列表同步

开关展示持久化与生命周期操作的结果，不以乐观状态冒充成功。

## 操作顺序

- 外部插件：[usePluginCatalog.ts](../../../src/app/pages/plugins/usePluginCatalog.ts) 等待 `setExternalPluginEnabled`，随后静默重读本机目录。
- 后端：[plugins.rs](../../../src-tauri/src/plugins.rs) 持久化启用状态，只同步该插件的 sidecar / 后台窗，再发送 `plugin-enabled-changed`。启动失败会撤销启用。
- 内置久坐提醒：[Plugins.tsx](../../../src/app/pages/Plugins.tsx) 等待 `setRestPluginEnabled` 成功后更新本地状态并发送 `catrace:plugin-enabled-changed`。
- 操作失败显示错误，再重读后端权威状态；普通配置自动保存不得覆盖外部插件的 `enabled`。

列表刷新与启停请求独立，避免启停时清空列表或闪动计数。启停只影响当前插件，见[sidecar 生命周期](sidecar启停与目录刷新边界.md)。
