# 插件面板和导航栏组件化拆分

## 背景

插件详情页原本在每个内置插件面板（Rest / Timer / Agent）里各自实现一个 header：图标、标题、副标题、总开关。外部插件在 `Plugins.vue` 里又单独实现了一套类似的 `ext-header`。左侧导航栏也直接写在 `Plugins.vue` 里，导致页面文件过长、样式重复。

## 本轮改动

### 新增组件

- `src/components/plugins/PluginPanelHeader.vue`
  - Props: `title`、`subtitle`、`enabled`、`loading`、`switchAriaLabel`
  - Emits: `update:enabled`
  - 图标通过 `#icon` slot 注入，保持各插件可自定义图标。
  - 内置使用 naive-ui `NSwitch`。

- `src/components/plugins/PluginNavRail.vue`
  - Props: `items: PluginNavItem[]`、`selectedId`、`loading`、`searchQuery`
  - Emits: `update:selectedId`、`update:searchQuery`、`refresh`、`openDir`
  - 负责左侧搜索、插件列表、状态点、版本/异常标签、刷新按钮、打开目录按钮。
  - 图标仍按 id 硬编码（rest / timer / agent / external），外部插件使用通用时钟图标。

### 修改点

- `src/views/Plugins.vue`
  - 删除左侧导航栏模板与全部 rail 样式。
  - 删除外部插件旧的 `ext-header` / `ext-meta` / `ext-dl` / `ext-trust` 等硬编码详情。
  - 外部插件详情改为复用 `PluginPanelHeader` + 下方占位内容区。
  - 保留外部插件错误提示和“发送测试通知”按钮。

- `src/components/plugins/RestPluginPanel.vue`
  - 删除本地 header 与相关 `.panel-header`、`.icon-badge`、`.panel-title` 等样式。
  - 使用 `PluginPanelHeader`。

- `src/components/plugins/TimerPluginPanel.vue`
  - 同上，删除本地 header 样式。
  - 注意：规则列表里的单条规则开关仍使用 `<n-switch>`，因此 `NSwitch` import 不能删。

- `src/components/plugins/AgentPluginPanel.vue`
  - 同上，删除本地 header 样式。

- `src/i18n/locales/zh-CN.ts` / `src/i18n/locales/en-US.ts`
  - 新增 `plugins.external.switchAria` 和 `plugins.external.settingsPlaceholder`。

## 外部插件布局现状

外部插件详情页现在只有统一 header 和下方占位区：

- header：插件 `manifest.name` 作为标题，`manifest.description` 作为副标题，开关控制启用。
- 内容区：暂时显示占位文案“插件设置面板由插件自身提供（暂未实现）”，并保留“发送测试通知”按钮。

后续若要接入外部插件自定义设置面板，需要扩展 manifest / Rust / 前端加载机制，不在本轮范围。

## 踩坑

清理 `TimerPluginPanel.vue` import 时，曾误把规则列表中用到的 `NSwitch` 也删除，导致运行时 `Failed to resolve component: n-switch`。恢复 import 后解决。说明面板 header 抽离后，仍需检查组件内部是否还有其他地方使用 `NSwitch`。
