# 2026-08-31 更新检查和下载允许用户换 GitHub 镜像源

## 背景

`tauri-plugin-updater` 的 JS `check()` 不能传 endpoints，源写死在 `tauri.conf.json`。国内镜像会挂；CI 又把安装包 URL 改写成 `ghproxy.net`，检查成功后下载仍可能失败。用户要能换源，更新 Toast 上也要能选。

## 决策

1. 源存在 SQLite `update_source`（不是 plugin-store），因为启动 3 秒自动检查在 Rust，要读同一份配置。
2. 自建 `check_app_update`：按源设 endpoints，把 Update 放进 webview resource table，前端再用 plugin 的 `downloadAndInstall`。
3. 锁定源时剥掉 latest.json 里的代理前缀，再按所选源重包下载 URL；`auto` 不改写，沿用 CI 的 ghproxy 链。

## 后果

- 设置页和更新 Toast 改源都会持久化，下次启动自动检查也走这个源。
- 默认 `auto`：ghfast → gh.ddlc → ghproxy → GitHub 直连。
