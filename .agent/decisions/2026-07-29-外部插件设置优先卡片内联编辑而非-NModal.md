# 2026-07-29 外部插件设置优先卡片内联编辑而非 NModal

## Context

timer 设置页用 `NModal` 做新建/编辑时：样式写在 `.timer-settings` 下全部失效（teleport 到 body），出现原生双轴滚动条、数字框错位；反复修 CSS 成本高。

## Decision

**复杂插件设置表单默认卡片内联展开**，不使用 `NModal`（除非极短确认）。

确认类仍可用 `NPopconfirm` / `useDialog`（短内容）。

## Consequences

- 样式作用域与列表卡一致，无 teleport  
- 可对照列表其它规则  
- 编辑态需禁用其它卡操作，避免双编辑  
- 长表单在宿主 PageScroll 内滚动，不自建 modal 滚动层  

## Alternatives rejected

1. 坚持 NModal + 把 CSS 挂到 `.timer-modal` — 可行但滚动/焦点/窄屏仍脆  
2. 整页路由编辑 — 过重，打断插件中心心智
