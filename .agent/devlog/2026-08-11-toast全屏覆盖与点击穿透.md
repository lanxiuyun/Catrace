# 2026-08-11 Toast 全屏覆盖 + 点击穿透

## Session goal
把 Toast 从「右下角通知堆叠」改为「全屏覆盖层 + 点击穿透」，下层应用可照常操作，只有卡片区域可交互；同时确保不覆盖任务栏。

## Completed
- Toast 窗口铺满光标所在显示器**工作区**（`work_area`），不再覆盖任务栏
- 穿透轮询线程（50ms）：前端上报卡片矩形（窗口内逻辑坐标），Rust 换算物理坐标做命中测试，切换整窗穿透 ↔ 卡片可交互
- Windows 点击穿透三层修复：raw 样式切换 + `WM_NCHITTEST` subclass + 每 tick 强制同步（详见 bug 记录）
- 前端：hit-region 上报（200ms 兜底 + ResizeObserver）、`catrace:toast-hover-exit` 驱动清 hover、单卡 hover 强制
- `handleMouseLeave` 不再因 hover 删除卡片（剩余时间归零时重置整段 auto-hide）
- 清理本轮所有调试日志（保留错误日志与功能日志），提交 `1325844`
