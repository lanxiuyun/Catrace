# 2026-09-03 插件页统一使用 Lucide 图标

## 会话目标

将插件页的手写 SVG 宿主图标替换为 Lucide，统一视觉风格；外部插件通过 `manifest.json` 提供的自定义图标仍然优先显示。

## 完成项

- 新增官方 `@lucide/vue` 依赖（未使用已弃用的 `lucide-vue-next`）。
- `PluginNavRail.vue`：刷新、安装、下拉、zip、文件夹、搜索，以及插件列表的内置/fallback 图标改用 Lucide。
- `Plugins.vue`：详情头的 rest、agent、external fallback 改用 Lucide；外部插件的 `iconDataUrl` 图片优先级不变。
- 外部插件图标约定保持：manifest 的 `icon` 是插件目录内相对路径，Rust 校验后转为 base64 data URL，由前端 `<img>` 渲染。
- 删除本轮遗留且未被引用的 `src-tauri/resources/rest_icon.svg` / `agent_icon.svg`。
- release bundled timer 未补 `icon`：当前 bundle 没有对应图标文件，继续使用 Lucide fallback，避免发布包出现坏引用。
