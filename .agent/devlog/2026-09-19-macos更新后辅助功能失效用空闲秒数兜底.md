# 2026-09-19 macOS 更新后辅助功能失效用空闲秒数兜底

## 会话目标

用户反馈 Mac 每次更新后都要重新授权，否则一直判定休息。落地横幅引导 + 免权限兜底采样，签名根治暂不做。

## 完成项

- `signal.rs`：`macos_perm_free` + `start_input_sampling_fallback`，未授权时用系统空闲秒数和光标位移喂 `ActivityState.count`（2s 语义不变）。
- `lib.rs`：未授权立刻开兜底；授权后停兜底再切完整采样。
- `AccessibilityBanner.vue` 挂 `MainShell`，2s 轮询，授权后收起。
- i18n `accessibilityBanner.*` 中英。
- 合入 `d480ff0` / PR #74。

## 验证

- `cargo check` / `pnpm vue-tsc --noEmit` 当时通过。
- 真机 Mac：未授权时活跃分钟应能涨、久坐应能弹、顶部有横幅；授权后横幅消失、按键统计恢复。最终以用户实机为准。
