# 2026-11-05 插件设置的多行输入框缩成一百多像素（选错 Radix 根类名）

## 症状

插件中心 → 久坐提醒详情的「提醒内容」多行输入框只有 ~176px 宽（同一张卡里的单行「提醒标题」是满宽 729px）。用户自己的长文案被字段内部滚动条截断，看起来像没写完的半截控件；构建、类型检查都不会报错。

## 根因

`src/app/pages/plugins.css` 写的是：

```css
.ct-plugin-row-control .rt-TextArea { width: 100%; }
```

Radix Themes 的 `TextArea` 根节点是 `.rt-TextAreaRoot`，`.rt-TextArea` 是内部 `<textarea>` 的类名（内部实际用的是 `.rt-TextAreaInput`）。选择器没命中，宽度规则静默失效，字段退回控件默认宽度。

## 修复

- 选择器改成 `.rt-TextAreaRoot`：`width: 100%` 生效，176 → 729px
- 多行输入加 `resize="vertical"`（与系统设置页「排除列表」一致，长文案可自己拖高）
- 同轮把「测试通知」按钮 `size="1"` → `size="2"`，和页面其它 32px 控件同一档

## 涉及文件

- `src/app/pages/plugins.css`
- `src/app/pages/plugins/RestSettings.tsx`

## 约定

Radix 的类名以 `node_modules/@radix-ui/themes/src/components/*.tsx` 或渲染出的 DOM 为准，写控件选择器后至少核对一次根节点类名。同类坑：`.rt-Button` 是按钮根类（`.rt-BaseButton` 只是它的基础类）；滑块是 `.rt-SliderTrack` / `.rt-SliderRange` 两个元素，别当同一个节点改。
