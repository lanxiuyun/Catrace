# 2026-09-19 macOS 更新后辅助功能授权失效导致一直休息

## 症状

Mac 每次应用更新后，仪表盘活跃分钟几乎不涨、整天被判休息。前台应用块还在，但键鼠像没动过。重新在「系统设置 → 辅助功能」勾选 Catrace 后恢复。

## 根因

macOS TCC 把辅助功能授权绑在**代码签名**上。CI 构建没有 Developer ID，只有 Tauri ad-hoc 签名，每次构建 cdhash 都变。updater 替换 `.app` 后，系统当成另一个应用，旧授权静默作废。

`device_query` 在 macOS 上无辅助功能权限时键鼠全是 0 → `ActivityState.count` 恒 0 → 每分钟 `count >= 3` 不成立 → 永远休息。前台 1Hz 采样不依赖该权限，所以时间线还有块。

提示原先只在系统设置卡，用户不打开设置无感。

## 修复（已合 PR #74）

- `signal.rs` `macos_perm_free`：免权限 API `CGEventSourceSecondsSinceLastEventType` + `CGEventGetLocation`。未授权时 `start_input_sampling_fallback` 按同样 2s 去重 / 2s 移动窗口喂 `count`，久坐判定照常。
- 授权后停兜底、切完整 `device_query` 采样（恢复按键计数）。
- `AccessibilityBanner.vue` 挂 `MainShell`：macOS 未授权时主窗顶部常驻引导，2s 轮询，授权后收起。
- 全部 `#[cfg(target_os = "macos")]`。Windows 路径不变。

已知取舍：未授权期间按键次数为 0；根治要 Apple Developer ID 稳定签名（未做）。
