# 轻量模式下关掉主窗口，整个 Catrace 直接退出

**日期**：2026-09-29
**状态**：已修

## 症状

开启轻量模式后点主窗右上角关闭按钮，`catrace.exe` 整个进程退出——托盘图标消失、采样与提醒全部停止，而不是「窗口消失、应用退到托盘」。

## 根因

Tauri 的默认行为是「**最后一个窗口关闭 → 应用退出**」（`RunEvent::ExitRequested`，`code == None`）。

第一期轻量模式上线时这个行为没有暴露：那时 github-notify / smsforwarder 各有一个隐藏的插件后台 WebView（`plugin-bg-<id>`）常驻，主窗销毁后它还在，应用就有窗口活着。第二期把这两个插件迁到 sidecar 后插件后台窗消失，于是「轻量模式关主窗」= 关掉最后一个窗口 → 应用退出。

## 修复

`run` 回调里拦截隐式退出（`src-tauri/src/lib.rs`）：

```rust
.build(tauri::generate_context!())
    .expect("error while building tauri application")
    .run(|_app, event| match event {
        tauri::RunEvent::ExitRequested { code, api, .. } => {
            if code.is_none() {
                // 窗口全部关闭的隐式退出：留在托盘
                api.prevent_exit();
            }
        }
        _ => {}
    });
```

判据是 `code`：`None` = 窗口全关触发的隐式退出，要拦；`Some(_)` = 程序化退出（托盘「退出」是 `app.exit(0)`、更新器是 `restart()`），必须放行，否则退不掉也重启不了。

注意 Tauri 2 里带回调的是 **`.build(context)` + `.run(callback)` 两段式**，不是 `.run(context, callback)`。

## 验证

轻量模式下发 `WM_CLOSE` 关主窗 → 进程存活，日志 `all windows closed, staying in tray (lightweight mode)`；再二次启动 exe 触发单实例回调 → 主窗重建、`IsHungAppWindow` 为 false；托盘「退出」仍能正常退出。
