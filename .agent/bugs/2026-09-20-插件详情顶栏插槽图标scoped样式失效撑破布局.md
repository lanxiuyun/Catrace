# 2026-09-20 插件详情顶栏插槽图标 scoped 样式失效撑破布局

## 症状

企业微信待办详情页标题区被一张巨大的蓝色图盖住（384×384 的 `icon.png` 按原始像素渲染），把标题、开关、下方提示全压住。Agent 通知 / PasteDrop 用 SVG（或走 Lucide 兜底）所以一直没暴露。

## 根因

`PluginPanelHeader.vue` 的 scoped CSS 写了 `.header-icon-img { width:100%; height:100% }`，但 `<img class="header-icon-img">` 是从 `Plugins.vue` 的 `#icon` 插槽塞进去的。Vue scoped 给子组件模板加 `data-v-xxx`，**插槽内容归父组件作用域**，子组件那条规则匹配不到 → img 无尺寸约束。

徽章本身是 `2.75rem`，没有 `overflow: hidden` 时大图直接溢出。

## 修复

- `PluginPanelHeader.vue`：`:deep(.header-icon-img)` 限制宽高 + `object-fit: cover`
- `.icon-badge` 加 `overflow: hidden` 兜底

## 涉及文件

- `src/components/plugins/PluginPanelHeader.vue`
- `src/views/mainWindow/Plugins.vue`（插槽里的 img，样式不要只写在子组件 scoped 里）

## 约定

凡是 slot 塞进子组件的元素，尺寸/布局要么写在父组件，要么子组件用 `:deep()`。新增插槽时默认检查约束是否真生效。
