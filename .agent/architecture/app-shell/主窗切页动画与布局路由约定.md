# 主窗切页动画与布局路由约定

## 布局路由

主窗四条一级页面（dashboard / plugins / settings / debug）挂在同一个 `/` 布局路由下，`MainShell` 用 `<Outlet />` 渲染当前页面，侧栏与全局 `<Toaster />` 保持挂载。

路由定义在 [router.tsx](../../../src/app/router.tsx)，导航项在 [MainShell.tsx](../../../src/app/shell/MainShell.tsx)。页面切换时只替换 Outlet 内容；页面组件会卸载，主壳本身不提供页面保活。

## 一级导航：交叉淡化

- 导航项使用 `<NavLink viewTransition>`，由 React Router 调用 View Transitions API。
- 文档根快照规则统一在 [shell.css](../../../src/app/shell/shell.css)：旧页 140ms 淡出、新页 200ms 淡入，均为 `ease-out`。
- 这些伪元素作用于文档根，页面样式不重复定义根快照动画。
- 不支持 View Transitions API 的 WebView 直接切换；`prefers-reduced-motion: reduce` 下关闭动画。

## 插件列表与详情：push / pop

插件中心的列表与详情有进入/返回关系，使用独立的方向性转场，不套用一级导航的交叉淡化。

- [PluginCenter.tsx](../../../src/app/pages/plugins/PluginCenter.tsx) 的 `runPageTransition` 给 `.ct-plugin-scroll` 临时设置 `ct-plugin-push` 或 `ct-plugin-back`，并用 `startViewTransition` 与 `flushSync` 提交内容切换。快照只覆盖页面滚动区，侧栏不参与。
- [plugins.css](../../../src/app/pages/plugins.css) 管理这两个命名快照的 push/pop 关键帧与 reduced-motion 降级。
- 详情状态放在 React Router history 的 `pluginDetail` 中；打开详情创建一条历史记录，返回关闭详情，系统后退/前进与按钮共用同一套状态。
- 从列表进入详情时从顶部开始；返回列表恢复列表滚动位置与触发卡片焦点。卸载后触发卡片不存在时，焦点回到当前列表 tab。

修改转场时同时核对按钮、系统后退/前进、卸载当前插件与连续返回，避免重复 history pop 或丢失焦点。

## 窗口边界

Toast、全屏提醒、弹窗与插件后台窗口是独立顶层路由，使用 `ToastShell` 与独立 React 页面，不进入主窗布局或导航转场。结构见 [应用外壳](README.md)。
