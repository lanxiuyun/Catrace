# 插件页左侧插件中心与右侧固定顶栏的布局约定

## 页面结构

插件页在应用全局顶栏下方占满主工作区。`MainShell` 本身不提供 scrollbar，每个页面自己声明滚动结构；插件页唯一纵向滚动区域是右侧 `plugin-scroll`，全局顶栏、左侧插件中心和右侧详情顶栏都固定：

```text
Plugins.vue
├── plugin-rail（15rem）
│   ├── rail-header（插件中心、数量、刷新）
│   ├── rail-search（本地筛选）
│   └── rail-list
│       ├── 插件列表与状态圆点
│       └── 探索更多插件
└── plugin-main
    ├── 固定 panel-header（PluginPanelHeader）
    └── plugin-scroll
        └── plugin-detail-wrapper
            └── plugin-detail-content
                └── .plugin-detail（max-width / padding / gap，宿主统一）
                    └── 各插件 Panel（只出业务：PluginSection...）
```

## 左侧插件中心

- 左栏宽度固定为 `15rem`，同时设置 `min-width` 和固定 flex basis；窗口变窄时也不允许被压缩或收窄。
- `rail-header` 与 `rail-search` 固定；插件列表区域复用公共 `PageScroll`，插件数量超出高度时只滚列表。
- 标题区只放插件中心、当前插件数量和刷新按钮，避免堆叠与插件管理无关的信息。
- 搜索只在前端过滤已加载插件，匹配名称、说明和插件 ID，不触发后端扫描。
- 状态圆点使用现有注册和启用状态：正常为绿色、未启用或未注册为灰色、加载错误为红色。
- “探索更多插件”当前复用打开本地插件目录的能力，不伪造尚不存在的插件市场入口。

## 右侧插件面板

`RestPluginPanel.vue`、`AgentPluginPanel.vue` 与外部插件 settings 顶部统一只显示图标、名称、描述和总开关（`PluginPanelHeader`）；测试、添加规则等插件专属内容放在下方业务区。

内容区外壳只在 `Plugins.vue` 的 `.plugin-detail`：最大宽度 `64rem`、水平居中、统一 padding 与 section gap。面板组件（内置 / 外部 settings）只负责业务，不再包一层 shell，也不要重复写 max-width/padding。

- `PluginSection.vue` 提供 `section-title` + `section-desc` + `section-card`（内置面板可复用）。
- 禁用态由父组件 `Plugins.vue` 统一灰显，面板内部不再写 `empty-state`。
- 右侧详情复用 `PageScroll fill-content` 并保留 `plugin-scroll` 语义 class；主壳永远不提供 scrollbar，插件页也不包整页 `PageScroll`。
- `.plugins-page` / `.plugin-main` 用 `overflow: hidden` 把 overflow 收敛到详情区；flex 子项的通用高度约束由 `PageScroll` 统一提供。
- `PageScroll fill-content` 让 scrollbar content 成为 `min-height: 100%` 的 column flex，短内容铺满、长内容形成 overflow。
- 外部插件 settings 若自带 scrollbar，宿主选择器不能穿透误伤。

## 全局顶栏约定

- 应用全局顶栏高度为 `3rem`，左 padding 固定为 `0.75rem`。
- 一级导航使用紧凑圆角选中态，不随窗口宽度动态扩大 padding。
- 交流群属于应用级辅助信息，放在全局顶栏最右侧的弱强调 Tag 中，不占插件侧栏空间。

## 涉及文件

- `src/views/mainWindow/MainShell.vue` — 全局顶栏、一级导航、交流群 Tag、单一 RouterView + KeepAlive；不创建 scrollbar。
- `src/components/PageScroll.vue` — Dashboard / Settings / Debug 使用的普通页面滚动壳。
- `src/views/mainWindow/Plugins.vue` — 插件中心侧栏、搜索、状态和左右布局。
- `src/components/plugins/PluginNavRail.vue` — 左侧插件中心。
- `src/components/plugins/PluginPanelHeader.vue` — 右侧固定顶栏（图标 + 标题/副标题 + 开关）。
- `src/components/plugins/PluginSection.vue` — 插件 Section 卡片公共组件。
- `src/components/plugins/RestPluginPanel.vue` — 久坐业务面板。
- `src/components/plugins/AgentPluginPanel.vue` — Agent 业务面板。
- 外部定时示例：`tools/plugin-demo/timer/settings.mjs`（宿主 `.plugin-detail` 管边距）。
